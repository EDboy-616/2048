# 2048

单文件 2048 小游戏 —— 零依赖、零网络请求，把 `2048.html` 存下来双击就能玩。

在线试玩（GitHub Pages 开启后）：https://edboy-616.github.io/2048/2048.html

## 玩法

相同数字的方块相撞就合并，目标是拼出目标数字。

- **键盘**：方向键 / WASD / HJKL 移动
- **触屏**：滑动移动；按住棋盘不动约 0.26 秒会浮出四个方向箭头，往哪边移哪个就点亮，松手即走（快速滑动不受影响）
- **撤销**：`U` 或 `Z` 键、点「撤销」按钮，最多回退 30 步
- **重开**：`R` 键、点「新游戏」

## 难度切换

右上角下拉框切换棋盘尺寸，目标数字也随尺寸变化：

| 尺寸 | 目标 | 说明 |
| --- | --- | --- |
| 3×3 | 512 | 快节奏，一步走错容易死局 |
| 4×4 | 2048 | 经典玩法（默认） |
| 5×5 | 8192 | 空间充裕，拼大数字 |

每种尺寸的最高分单独保存（localStorage）。

## 其他特性

- 合并、胜利、失败音效（Web Audio 现场合成，无音频文件），右上角开关
- 通关后可选择「继续」接着拼更大的数字
- 得分飘字、合并弹跳、无效移动抖动等动画反馈
- 响应式布局，手机竖屏到桌面都能玩

## 运行

无需安装任何东西：

- 直接双击 `2048.html`，或
- 本地起个静态服务：`python -m http.server 8000`，然后访问 http://localhost:8000/2048.html

## 技术

- 一个 HTML 文件包含全部 CSS 和 JavaScript（原生实现，无框架）
- 方块用绝对定位 + `transform` 过渡做滑动动画
- 棋盘尺寸由 CSS 变量 `--n` / `--cell` / `--gap` 驱动，切尺寸只改一个变量
